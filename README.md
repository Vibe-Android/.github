# Vibe

Vibe is an open-source Android ROM focused on customization, a clean user experience, and Pixel devices.

## About

Vibe is currently in early development and is based on LineageOS.

The project aims to combine:

- extensive customization
- a clean and consistent UI
- Pixel-focused support
- useful features without unnecessary bloat

## Initial device support

- Google Pixel 6 Pro (`raven`)

## Base

- LineageOS 23.2

## Status

Early bring-up.  
The project is not yet ready for daily use.

## Repositories

- `android_manifest` — manifests and build configuration
- more repositories will be added as development progresses
